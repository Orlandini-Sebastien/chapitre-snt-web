PHASE 2 : STRUCTURE HTML (20 minutes)
================================================================================

**Étape A : Créer l'architecture (5 min)**

Organisez vos fichiers :
```
Mon_Portfolio_Final/
├── index.html (page d'accueil)
├── about.html (à propos)

├── style.css (styles communs)
└── images/ (vos photos)
```

**Étape B : Page d'accueil moderne (8 min)**

Créez index.html avec cette structure :

```html
<!DOCTYPE html>
<html>
<head>
    <title>[Votre Nom] - Portfolio</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <!-- Navigation principale -->
    <nav class="navbar">
        <div class="nav-brand">[Initiales]</div>
        <div class="nav-links">
            <a href="index.html" class="actif">Accueil</a>
            <a href="about.html">À propos</a>
            <a href="projets.html">Projets</a>
            <a href="interactive.html">Interactif</a>
        </div>
    </nav>
    
    <!-- Section héros -->
    <section class="hero">
        <h1 class="hero-title">Bonjour, je suis [Votre Nom]</h1>
        <p class="hero-subtitle">[Votre description en une phrase]</p>
        <button onclick="scrollToAbout()" class="hero-btn">Découvrir mon profil</button>
    </section>
    
    <!-- Aperçu des compétences -->
    <section class="competences-apercu">
        <h2>Mes compétences</h2>
        <div class="competences-grid">
            <div class="competence-card">
                <div class="competence-icon">📝</div>
                <h3>HTML</h3>
                <div class="competence-bar">
                    <div class="competence-progress" data-progress="80"></div>
                </div>
            </div>
            <!-- Répétez pour CSS et JavaScript -->
        </div>
    </section>
    
    <!-- JavaScript pour l'interactivité -->
    <script>
        function scrollToAbout() {
            // Animation de scroll ou redirection
            window.location.href = "about.html";
        }
        
        // Animation des barres de compétences au chargement
        window.onload = function() {
            animerCompetences();
        };
        
        function animerCompetences() {
            let barres = document.querySelectorAll('.competence-progress');
            barres.forEach(barre => {
                let progress = barre.getAttribute('data-progress');
                barre.style.width = progress + '%';
            });
        }
    </script>
</body>
</html>
```

**Étape C : Section héros impressionnante (8 min)**

```css

    background: linear-gradient(135deg, var(--couleur-accent), var(--couleur-secondaire));
    color: white;
    text-align: center;

    font-size: 1.5rem;

    animation: slideInUp 1s ease-out 0.5s both;
}

.hero-btn {
    background: white;
    color: var(--couleur-accent);
    border: none;
    padding: 15px 30px;
    font-size: 1.1rem;
    border-radius: 25px;
    cursor: pointer;
    transition: all 0.3s ease;
    animation: fadeIn 1s ease-out 1s both;
}

.hero-btn:hover {
    transform: translateY(-3px);
    box-shadow: 0 5px 15px rgba(0,0,0,0.2);
}

/* Animations */
@keyframes slideInDown {
    from { opacity: 0; transform: translateY(-50px); }
    to { opacity: 1; transform: translateY(0); }
}

@keyframes slideInUp {
    from { opacity: 0; transform: translateY(50px); }
    to { opacity: 1; transform: translateY(0); }
}

@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
}
```

2. **Mode sombre/clair** :
```javascript
function toggleTheme() {
    document.body.classList.toggle('dark-theme');
    let bouton = document.getElementById('theme-toggle');
    bouton.innerHTML = document.body.classList.contains('dark-theme') ? '☀️' : '🌙';
}
```

3. **Formulaire de contact avec validation** :
```javascript
function validerFormulaire() {
    let nom = document.getElementById('nom').value;
    let email = document.getElementById('email').value;
    
    if (nom === '' || email === '') {
        alert('Veuillez remplir tous les champs');
        return false;
    }
    
    alert('Message envoyé ! Merci ' + nom);
    return true;
}
```
