================================================================================
ERREURS FRÉQUENTES ET SOLUTIONS
================================================================================

ERREUR 1 : Balises non fermées
Symptôme : Texte qui s'affiche tout en gras ou en titre
Solution : Vérifier que chaque <balise> a sa </balise>
Exemple : <strong>texte (FAUX) → <strong>texte</strong> (CORRECT)

ERREUR 2 : Extension de fichier incorrecte
Symptôme : Le fichier ne s'ouvre pas dans le navigateur
Solution : Vérifier que le fichier se termine par .html
Conseil : Afficher les extensions de fichiers dans l'explorateur

ERREUR 3 : Balises imbriquées incorrectement
Symptôme : Affichage étrange ou balises visibles
Solution : Les balises doivent s'ouvrir et se fermer dans l'ordre
Exemple : <p><strong>texte</p></strong> (FAUX)
         <p><strong>texte</strong></p> (CORRECT)

ERREUR 4 : Caractères spéciaux dans le nom de fichier
Symptôme : Fichier qui ne s'ouvre pas
Solution : Éviter espaces, accents, caractères spéciaux
Exemple : "ma page.html" (FAUX) → "ma_page.html" (CORRECT)
