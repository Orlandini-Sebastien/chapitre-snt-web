================================================================================
ERREURS FRÉQUENTES ET SOLUTIONS
================================================================================

ERREUR 1 : Le style ne s'applique pas du tout
Symptôme : La page reste identique à la séance précédente
Causes possibles :
- Fichier mal nommé (Style.css au lieu de style.css)
- Lien incorrect dans HTML : href="Style.css" au lieu de "style.css"
- Fichier CSS et HTML dans des dossiers différents
Solution : Vérifier l'orthographe exacte et l'emplacement des fichiers

ERREUR 2 : Syntaxe CSS incorrecte
Symptôme : Certains styles ne s'appliquent pas
Exemples d'erreurs :
- h1 { color red; } → manque les deux-points :
- p { color: blue } → manque le point-virgule ;
- .classe { color: blue; → manque l'accolade fermante }
Solution : Vérifier chaque déclaration CSS

ERREUR 3 : Confusion classe/ID dans le CSS
Symptôme : Les classes ne fonctionnent pas
Erreur fréquente : #centre au lieu de .centre dans le CSS
Rappel : .classe dans CSS, class="classe" dans HTML

ERREUR 4 : Balise <link> mal placée
Symptôme : Styles non appliqués malgré un CSS correct
Solution : La balise <link> doit être dans le <head>, pas dans le <body>
