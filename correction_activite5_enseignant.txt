================================================================================
ERREURS FRÉQUENTES ET SOLUTIONS
================================================================================

ERREUR 1 : Liens qui ne fonctionnent pas
Symptômes : Error 404, liens morts
Causes :
- Faute d'orthographe dans le nom de fichier
- Fichiers non dans le même dossier
- Extension .html oubliée
Solutions :
- Vérifier l'orthographe exacte : about.html (pas About.html)
- Tous les fichiers dans le même dossier "Mon_Site_Web"
- Toujours inclure l'extension .html

ERREUR 2 : CSS qui ne s'applique pas sur certaines pages
Symptôme : Style différent ou absent sur une page
Cause : Lien vers CSS incorrect ou manquant
Solution : 
- Vérifier <link rel="stylesheet" href="style.css"> sur toutes les pages
- Même chemin relatif sur toutes les pages

ERREUR 3 : Classe "actif" mal utilisée
Symptôme : Page active non mise en évidence
Solution :
- Sur index.html : <a href="index.html" class="actif">Accueil</a>
- Sur about.html : <a href="about.html" class="actif">À propos</a>
- Sur projets.html : <a href="projets.html" class="actif">Mes projets</a>

ERREUR 4 : Liens externes mal formés
Symptôme : Liens qui n'ouvrent pas de nouvelle fenêtre
Solution :
- Toujours inclure http:// ou https://
- Ajouter target="_blank" pour nouvelle fenêtre
Correct : <a href="https://www.google.com" target="_blank">Google</a>

ERREUR 5 : Structure de navigation incohérente
Symptôme : Menus différents selon les pages
Solution : Copier-coller exactement le même menu sur toutes les pages
(seule la classe "actif" change)
