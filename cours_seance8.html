⭐ Critères d'évaluation

Grille de notation

🏗️ Structure HTML (5 pts)

  • Code HTML valide et bien structuré
  • Utilisation appropriée des balises
  • Navigation fonctionnelle

🎨 Design CSS (5 pts)

  • Mise en forme cohérente et moderne
  • Utilisation avancée des propriétés
  • Responsive design basique

⚡ JavaScript (4 pts)

  • Au moins 2 interactions fonctionnelles
  • Code JavaScript propre
  • Créativité dans les fonctionnalités

🎯 Créativité (3 pts)

  • Originalité du contenu
  • Personnalisation poussée
  • Fonctionnalités bonus

📝 Documentation (3 pts)

  • Code commenté
  • Organisation des fichiers
  • README explicatif
