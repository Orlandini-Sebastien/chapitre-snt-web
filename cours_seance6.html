📝 Les bases de JavaScript

12 min

1. Les variables

Pour stocker des informations :

let nom = "Marie";
let age = 16;
let message = "Bonjour " + nom;
let = créer une variable
= = attribuer une valeur
+ = assembler du texte

2. Les fonctions

Pour exécuter des actions :

function direBonjour() {
    alert("Bonjour tout le monde !");
}

direBonjour(); // Appeler la fonction
function = créer une fonction
{ } = contenu de la fonction
alert() = afficher un message

3. Les événements

Pour réagir aux actions de l'utilisateur :

// Dans le HTML :
<button onclick="direBonjour()">Cliquez-moi</button>

// Quand on clique, la fonction direBonjour() s'exécute
onclick = quand on clique
onmouseover = quand la souris passe dessus
onchange = quand quelque chose change

📋 Exemple complet : Page interactive

HTML :

<button onclick="changerCouleur()">Changer la couleur</button>
<p id="monTexte">Ce texte va changer !</p>

JavaScript :

function changerCouleur() {
    let texte = document.getElementById("monTexte");
    texte.style.color = "red";
    texte.innerHTML = "Le texte a changé !";
}

Résultat :

Ce texte va changer !
