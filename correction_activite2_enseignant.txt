ERREURS FRÉQUENTES ET SOLUTIONS
================================================================================

ERREUR 1 : Hiérarchie des titres incorrecte
Symptôme : h3 utilisé sans h2, plusieurs h1 sur la page
Solution : Rappeler la règle : UN h1 par page, puis h2, puis h3 sous h2
Exemple incorrect : <h1>Titre</h1> <h3>Sous-titre</h3>
Exemple correct : <h1>Titre</h1> <h2>Section</h2> <h3>Sous-section</h3>

ERREUR 2 : Structure de liste incorrecte
Symptôme : <li> utilisé sans <ul>, oubli de balises fermantes
Solution : Insister sur la structure obligatoire <ul><li>...</li></ul>
Exemple incorrect : <li>Item 1</li><li>Item 2</li>
Exemple correct : <ul><li>Item 1</li><li>Item 2</li></ul>

ERREUR 3 : Image qui ne s'affiche pas
Symptôme : Carré avec X ou texte alternatif visible
Solution : 
- Vérifier que l'image est dans le bon dossier
- Vérifier l'orthographe du nom de fichier
- Vérifier l'extension (jpg, png)
- Expliquer l'importance de l'attribut alt

ERREUR 4 : Lien non fonctionnel
Symptôme : Lien qui ne s'ouvre pas ou erreur 404
Solution : Vérifier la présence de http:// ou https://
Exemple incorrect : <a href="wikipedia.org">
Exemple correct : <a href="https://www.wikipedia.org">

ERREUR 5 : Attributs d'image manquants
Symptôme : Image trop grande ou sans description
Solution : Expliquer l'importance de width et alt
Exemple complet : <img src="photo.jpg" alt="Description" width="200">
