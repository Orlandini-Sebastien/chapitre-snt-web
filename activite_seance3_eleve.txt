MATÉRIEL NÉCESSAIRE
================================================================================

✓ Votre fichier index.html de la séance 2
✓ Bloc-notes (ou Notepad++)
✓ Navigateur web
✓ Cette fiche d'activité

================================================================================
ÉTAPE 1 : CRÉER LE FICHIER CSS (10 minutes)
================================================================================

1. Ouvrez votre dossier "Mon_Site_Web"
2. Créez un nouveau fichier dans le Bloc-notes
3. Enregistrez-le IMMÉDIATEMENT sous le nom : style.css
   ATTENTION : Bien mettre l'extension .css !

4. Dans le fichier style.css, tapez ce premier code :

/* Ma première feuille de style CSS */

body {
    font-family: Arial, sans-serif;
    background-color: lightblue;
    margin: 20px;
}

h1 {
    color: darkblue;
    text-align: center;
    font-size: 28px;
}

5. Sauvegardez (Ctrl + S)

================================================================================
ÉTAPE 2 : LIER CSS À HTML (5 minutes)
================================================================================

1. Ouvrez votre fichier index.html avec le Bloc-notes
2. Dans la partie <head>, APRÈS la ligne <title>, ajoutez :

<link rel="stylesheet" href="style.css">

Votre <head> doit ressembler à ceci :

<head>
    <title>Ma première page - [Votre Nom]</title>
    <link rel="stylesheet" href="style.css">
</head>

3. Sauvegardez le fichier HTML
4. Ouvrez index.html dans votre navigateur
5. MAGIE ! ✨ Votre page a changé d'apparence !

================================================================================
ÉTAPE 3 : STYLISER LES SECTIONS (15 minutes)
================================================================================

Retournez dans style.css et ajoutez ces styles APRÈS ce qui existe déjà :

h2 {
    color: green;
    border-bottom: 2px solid green;
    padding-bottom: 5px;
}

h3 {
    color: orange;
    font-style: italic;
}

p {
    color: black;
    line-height: 1.5;
    text-align: justify;
}

ul {
    background-color: lightyellow;
    padding: 15px;
    border-radius: 10px;
}

li {
    margin-bottom: 5px;
}

strong {
    color: red;
    font-size: 18px;
}

Sauvegardez et actualisez votre page (F5) pour voir les changements !

================================================================================
ÉTAPE 4 : CRÉER DES CLASSES PERSONNALISÉES (10 minutes)
================================================================================

1. Dans style.css, ajoutez à la fin :

.important {
    background-color: yellow;
    padding: 10px;
    border: 3px solid orange;
    border-radius: 5px;
    font-weight: bold;
}

.centre {
    text-align: center;
}

.rouge {
    color: red;
}

2. Dans votre fichier HTML, ajoutez ces classes :

- Sur votre titre h1, ajoutez : class="centre"
  Exemple : <h1 class="centre">Portfolio de [Votre Nom]</h1>

- Sur un paragraphe important, ajoutez : class="important"
  Exemple : <p class="important">Cette page web est ma première création !</p>

- Sur un mot, ajoutez : class="rouge"
  Exemple : <strong class="rouge">SNT</strong>

3. Sauvegardez tout et actualisez !

================================================================================
PROBLÈMES FRÉQUENTS
================================================================================

PROBLÈME : Le style ne s'applique pas
SOLUTION : 
- Vérifiez que le fichier s'appelle bien "style.css"
- Vérifiez la ligne <link> dans le HTML
- Vérifiez qu'il n'y a pas d'erreurs de syntaxe dans le CSS

PROBLÈME : Erreur de syntaxe CSS
SOLUTION :
- Vérifiez que chaque propriété finit par un point-virgule ;
- Vérifiez que les accolades { } sont bien fermées
- Vérifiez l'orthographe des propriétés

PROBLÈME : La classe ne fonctionne pas
SOLUTION :
- Dans CSS : .nomclasse (avec le point)
- Dans HTML : class="nomclasse" (sans le point)
