ÉTAPE 1 : RÉORGANISER LE CONTENU (10 minutes)
================================================================================

1. Dans votre dossier "Mon_Site_Web", créez une copie de index.html :
   - Copiez index.html → Collez → Renommez en index_complet.html

2. Ouvrez index.html et SIMPLIFIEZ-LE pour garder seulement :

<!DOCTYPE html>
<html>
<head>
    <title>Portfolio de [Votre Nom] - Accueil</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <nav class="menu">
        <a href="index.html">Accueil</a>
        <a href="about.html">À propos</a>
        <a href="projets.html">Mes projets</a>
    </nav>
    
    <div class="carte">
        <h1>Bienvenue sur mon Portfolio</h1>
        <p>Je suis <strong>[Votre Nom]</strong>, élève en 2nde GT.</p>
        <p>Découvrez qui je suis, mes passions et mes projets !</p>
        <p class="important">Utilisez le menu ci-dessus pour naviguer.</p>
    </div>
    
    <div class="carte">
        <h2>Navigation rapide</h2>
        <p>→ <a href="about.html">En savoir plus sur moi</a></p>
        <p>→ <a href="projets.html">Voir mes projets</a></p>
    </div>
</body>
</html>

ÉTAPE 4 : AMÉLIORER LE CSS POUR LA NAVIGATION (5 minutes)
================================================================================

Ajoutez ce code à la FIN de votre fichier style.css :

/* Menu de navigation */
.menu {
    background: linear-gradient(135deg, #2C3E50, #4A6741);
    padding: 15px;
    text-align: center;
    margin-bottom: 20px;
    border-radius: 10px;
}

.menu a {
    color: white;
    text-decoration: none;
    padding: 10px 20px;
    margin: 0 10px;
    border-radius: 5px;
    font-weight: bold;
    transition: all 0.3s ease;
}

.menu a:hover {
    background-color: rgba(255, 255, 255, 0.2);
    transform: translateY(-2px);
}

.menu a.actif {
    background-color: #4A90E2;
    color: white;
}

================================================================================
PROBLÈMES FRÉQUENTS
================================================================================

PROBLÈME : Les liens ne fonctionnent pas
SOLUTION :
- Vérifiez l'orthographe des noms de fichiers
- Les fichiers doivent être dans le même dossier
- Respectez la casse : about.html (pas About.html)

PROBLÈME : Le CSS ne s'applique pas sur les nouvelles pages
SOLUTION :
- Vérifiez la ligne <link rel="stylesheet" href="style.css">
- Elle doit être identique sur toutes les pages

PROBLÈME : Les liens externes s'ouvrent dans la même fenêtre
SOLUTION :
- Ajoutez target="_blank" à vos liens externes
- Exemple : <a href="https://..." target="_blank">
