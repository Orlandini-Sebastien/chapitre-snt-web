📁 Organisation des fichiers

7 min

🗂️ Arborescence recommandée

📁 Mon_Site_Web/
📄 index.html (page d'accueil)
📄 about.html (page à propos)
📄 projets.html (page projets)
🎨 style.css (feuille de style)
📁 images/
🖼️ photo.jpg

🛤️ Chemins relatifs vs absolus

Chemin relatif ✅

Par rapport au fichier actuel

about.html → Dans le même dossier
images/photo.jpg → Dans le sous-dossier images

Chemin absolu ⚠️

Adresse complète (éviter)

C:\Users\Marie\Desktop\about.html → Ne fonctionne que sur votre PC

💡 Bonne pratique

Toujours utiliser des chemins relatifs pour que votre site fonctionne partout !

🧭 Conseils pour la navigation :

  • Menu cohérent : Même menu sur toutes les pages
  • Lien "retour" : Toujours permettre de revenir à l'accueil
  • Page active : Indiquer où on se trouve
  • Tester tous les liens : Vérifier qu'ils fonctionnent

📚 À retenir de cette séance :

  • Balise <a href=""> pour créer des liens

  • Navigation cohérente entre pages
