Qu'est-ce que le DOM ?

DOM = Document Object Model (Modèle d'Objet du Document)

C'est la représentation de votre page HTML que JavaScript peut modifier

document
html
body
h1
p
button

JavaScript peut :

  • 📝 Modifier le texte
  • 🎨 Changer les styles
  • ➕ Ajouter des éléments
  • ❌ Supprimer des éléments

🔧 Méthodes essentielles

Sélectionner un élément

document.getElementById("monId")

Trouve l'élément avec id="monId"

Changer le contenu

element.innerHTML = "Nouveau texte"

Modifie le contenu HTML

Changer le style

element.style.color = "red"

Modifie l'apparence CSS

Ajouter une classe

element.classList.add("nouvelle-classe")

Applique un style CSS
