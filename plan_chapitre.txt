CHAPITRE : ÉLABORATION D'UN SITE WEB INTERACTIF
Niveau : 2nde GT - SNT
Durée : 8 heures (8 séances de 1h)

=====================================
STRUCTURE GÉNÉRALE DU CHAPITRE
=====================================

SÉANCE 1 (1h) : DÉCOUVERTE DU WEB ET HTML DE BASE
- Objectifs : Comprendre le Web, créer sa première page HTML
- Cours (15min) : Le Web et le HTML
- Pratique (45min) : Activité 1 - Ma première page web

SÉANCE 2 (1h) : HTML - STRUCTURE ET CONTENU
- Objectifs : Maîtriser les balises essentielles et la structure
- Cours (15min) : Balises, hiérarchie, attributs
- Pratique (45min) : Activité 2 - Structurer du contenu

SÉANCE 3 (1h) : INTRODUCTION AU CSS
- Objectifs : Découvrir le CSS et les sélecteurs de base
- Cours (20min) : CSS, sélecteurs, propriétés
- Pratique (40min) : Activité 3 - Mes premiers styles

SÉANCE 4 (1h) : CSS - MISE EN FORME AVANCÉE
- Objectifs : Layout, couleurs, typographie
- Cours (15min) : Propriétés avancées, organisation
- Pratique (45min) : Activité 4 - Une page stylée

SÉANCE 5 (1h) : LIENS ET NAVIGATION
- Objectifs : Créer un site multi-pages avec navigation
- Cours (15min) : Liens, URLs, arborescence
- Pratique (45min) : Activité 5 - Un site à plusieurs pages

SÉANCE 6 (1h) : INTRODUCTION AU JAVASCRIPT
- Objectifs : Découvrir JavaScript pour l'interactivité
- Cours (20min) : JavaScript, variables, événements
- Pratique (40min) : Activité 6 - Mes premières interactions

SÉANCE 7 (1h) : JAVASCRIPT - INTERACTIVITÉ SIMPLE
- Objectifs : Créer des animations et interactions
- Cours (15min) : Manipulation du DOM, animations CSS+JS
- Pratique (45min) : Activité 7 - Page interactive

SÉANCE 8 (1h) : PROJET FINAL
- Objectifs : Réaliser un mini-site personnel interactif
- Cours (10min) : Récapitulatif et bonnes pratiques  
- Pratique (50min) : Projet - Mon site interactif

=====================================
SUPPORTS À CRÉER
=====================================

Pour chaque séance :
1. Support de cours (HTML + CSS pour affichage)
2. Fiche activité élève (TXT pour impression)
3. Correction activité (TXT)
4. Fichiers exemples/ressources

Total : 16 documents + ressources
