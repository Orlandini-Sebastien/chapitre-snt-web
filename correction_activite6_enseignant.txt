1. CHANGEUR DE COULEUR :

function changerCouleur() {
    let couleurs = ["lightblue", "lightgreen", "lightpink", "lightyellow", "lightcoral"];
    let hasard = Math.floor(Math.random() * couleurs.length);
    document.body.style.backgroundColor = couleurs[hasard];
    alert("Nouvelle couleur appliquée !");
}

2. COMPTEUR DE CLICS :

let nombreClics = 0;

function incrementer() {
    nombreClics = nombreClics + 1;
    document.getElementById("compteur").innerHTML = nombreClics;
    
    if (nombreClics === 10) {
        alert("Bravo ! Vous avez atteint 10 clics !");
    }
}

function reset() {
    nombreClics = 0;
    document.getElementById("compteur").innerHTML = nombreClics;
}

3. SALUTATION PERSONNALISÉE :

function direBonjour() {
    let nom = document.getElementById("nomUtilisateur").value;
    let message = document.getElementById("message-salut");
    
    if (nom === "") {
        message.innerHTML = "❌ Veuillez entrer votre nom !";
        message.style.color = "red";
    } else {
        message.innerHTML = "🎉 Bonjour " + nom + " ! Bienvenue sur mon site !";
        message.style.color = "green";
    }
}

ERREURS FRÉQUENTES ET SOLUTIONS
================================================================================

ERREUR 1 : "ReferenceError: fonction is not defined"
Symptôme : Erreur dans la console quand on clique sur un bouton
Causes :
- Faute de frappe dans le nom de fonction
- Fonction déclarée après son utilisation
- Fonction dans un autre fichier script
Solutions :
- Vérifier l'orthographe exacte
- Déclarer la fonction avant de l'appeler
- Tout mettre dans le même <script>

ERREUR 2 : "TypeError: Cannot read property 'innerHTML' of null"
Symptôme : getElementById retourne null
Causes :
- ID inexistant dans le HTML
- Faute de frappe dans l'ID
- Script exécuté avant le chargement du DOM
Solutions :
- Vérifier l'orthographe de l'ID
- S'assurer que l'élément existe
- Mettre le script à la fin du body

ERREUR 3 : Variables non sauvegardées
Symptôme : Le compteur repart à 0 à chaque clic
Cause : Variable déclarée dans la fonction au lieu d'être globale
Solution : Déclarer let nombreClics = 0; HORS de la fonction

ERREUR 4 : Math.random() mal utilisé
Erreurs fréquentes :
- Math.random() * couleurs.length (donne des décimales)
- Math.random(couleurs.length) (syntaxe incorrecte)
Solution correcte : Math.floor(Math.random() * couleurs.length)

ERREUR 5 : Concatenation de strings
Erreur : nombreClics = nombreClics + 1 devient "01" au lieu de 1
Cause : Récupération en string au lieu de number
Solution : Utiliser parseInt() ou s'assurer du type number
