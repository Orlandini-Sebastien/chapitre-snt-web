📝 HTML : Le langage des pages web

10 min

HTML = HyperText Markup Language

C'est le langage qui permet de créer des pages web

🏗️
HTML
Structure de la page
+
🎨
CSS
Style et couleurs
+
⚡
JavaScript
Interactivité

Votre première page HTML :

<!DOCTYPE html>
<html>
<head>
    <title>Ma page</title>
</head>
<body>
    <h1>Bonjour !</h1>
    <p>Bienvenue sur ma page.</p>
</body>
</html>

Les balises indispensables :

<h1> Titre
<p> Paragraphe
<strong> Gras
<br> Nouvelle ligne

🎯 Activité 1 : Ma première page web

45 min

Vous allez créer votre toute première page web ! Pas de panique, on commence simple.

1 Ouvrir le Bloc-notes
2 Écrire le code HTML
3 Sauvegarder en .html
4 Ouvrir dans le navigateur
Objectif : Créer une page qui parle de vous avec un titre, des paragraphes et du texte en gras.

🔧 Outils nécessaires :

  • Bloc-notes (ou Notepad++)
  • Navigateur web (Chrome, Firefox...)
  • Fiche activité distribuée
