ÉTAPE 2 : PREMIER BOUTON INTERACTIF (10 minutes)
================================================================================

Ajoutez ce code AVANT la balise </script> dans interactive.html :

<div class="carte">
    <h2>🎨 Changeur de couleur</h2>
    <p>Cliquez sur le bouton pour changer la couleur de fond !</p>
    <button onclick="changerCouleur()" class="bouton-js">Changer la couleur</button>
</div>

<script>
function changerCouleur() {
    // Liste de couleurs
    let couleurs = ["lightblue", "lightgreen", "lightpink", "lightyellow", "lightcoral"];
    
    // Choisir une couleur au hasard
    let hasard = Math.floor(Math.random() * couleurs.length);
    
    // Changer la couleur de fond
    document.body.style.backgroundColor = couleurs[hasard];
    
    // Afficher un message
    alert("Nouvelle couleur appliquée !");
}
</script>

ÉTAPE 3 : COMPTEUR DE CLICS (10 minutes)
================================================================================

Ajoutez cette section :

<div class="carte">
    <h2>🔢 Compteur de clics</h2>
    <p>Nombre de clics : <span id="compteur">0</span></p>
    <button onclick="incrementer()" class="bouton-js">Cliquer ici !</button>
    <button onclick="reset()" class="bouton-js rouge">Remettre à zéro</button>
</div>

Et ajoutez ce JavaScript :

let nombreClics = 0;

function incrementer() {
    nombreClics = nombreClics + 1;
    document.getElementById("compteur").innerHTML = nombreClics;
    
    if (nombreClics === 10) {
        alert("Bravo ! Vous avez atteint 10 clics !");
    }
}

function reset() {
    nombreClics = 0;
    document.getElementById("compteur").innerHTML = nombreClics;
}

ÉTAPE 4 : MESSAGE PERSONNALISÉ (10 minutes)
================================================================================

Ajoutez cette section :

<div class="carte">
    <h2>👋 Salutation personnalisée</h2>
    <p>Entrez votre nom :</p>
    <input type="text" id="nomUtilisateur" placeholder="Tapez votre nom">
    <button onclick="direBonjour()" class="bouton-js">Me saluer !</button>
    <p id="message-salut"></p>
</div>

Et ce JavaScript :

function direBonjour() {
    let nom = document.getElementById("nomUtilisateur").value;
    let message = document.getElementById("message-salut");
    
    if (nom === "") {
        message.innerHTML = "❌ Veuillez entrer votre nom !";
        message.style.color = "red";
    } else {
        message.innerHTML = "🎉 Bonjour " + nom + " ! Bienvenue sur mon site !";
        message.style.color = "green";
    }
}

================================================================================
PROBLÈMES FRÉQUENTS
================================================================================

PROBLÈME : "ReferenceError: fonction is not defined"
SOLUTION : 
- Vérifiez l'orthographe du nom de fonction
- Assurez-vous que la fonction est définie avant l'appel

PROBLÈME : Les variables ne se sauvegardent pas
SOLUTION :
- Déclarez les variables HORS des fonctions (variables globales)
- Exemple : let nombreClics = 0; (au début du script)

PROBLÈME : getElementById retourne null
SOLUTION :
- Vérifiez l'orthographe de l'id dans le HTML et JS
- L'id doit être unique sur la page

DÉFIS BONUS (Si vous avez fini en avance)
================================================================================

1. **Générateur de phrases** :
   - Créez des listes de mots (noms, adjectifs, verbes)
   - Générez des phrases aléatoires amusantes

2. **Mini-quiz** :
   - Posez une question avec prompt()
   - Vérifiez la réponse et affichez le score

3. **Calculatrice simple** :
   - Deux champs pour les nombres
   - Boutons +, -, ×, ÷
   - Affichage du résultat

Exemple de générateur de phrases :
```javascript
function genererPhrase() {
    let noms = ["chat", "chien", "oiseau", "poisson"];
    let adjectifs = ["mignon", "drôle", "intelligent", "coloré"];
    let verbes = ["court", "mange", "danse", "chante"];
    
    let nom = noms[Math.floor(Math.random() * noms.length)];
    let adj = adjectifs[Math.floor(Math.random() * adjectifs.length)];
    let verbe = verbes[Math.floor(Math.random() * verbes.length)];
    
    let phrase = "Le " + nom + " " + adj + " " + verbe + ".";
    document.getElementById("phrase-aleatoire").innerHTML = phrase;
}
```
