================================================================================
SNT 2nde GT - SÉANCE 2 - ACTIVITÉ 2 : STRUCTURER DU CONTENU
================================================================================

Durée : 45 minutes
Objectif : Améliorer votre page web avec de nouvelles balises HTML

================================================================================
MATÉRIEL NÉCESSAIRE
================================================================================

✓ Votre fichier index.html de la séance 1
✓ Bloc-notes (ou Notepad++)
✓ Navigateur web
✓ Une photo personnelle (optionnel) : format JPG ou PNG, taille max 1 Mo

================================================================================
ÉTAPE 1 : PRÉPARATION (5 minutes)
================================================================================

1. Ouvrez votre dossier "Mon_Site_Web" sur le Bureau
2. Faites une copie de votre fichier index.html
   - Clic droit sur index.html → Copier
   - Clic droit dans le dossier → Coller
   - Renommez la copie en : index_sauvegarde.html
3. Ouvrez le fichier index.html original avec le Bloc-notes

================================================================================
ÉTAPE 2 : TRANSFORMER EN PORTFOLIO (15 minutes)
================================================================================

Remplacez TOUT le contenu entre <body> et </body> par le code suivant :

<body>
    <h1>Portfolio de [Votre Nom]</h1>
    
    <h2>À propos de moi</h2>
    <p>Je suis <strong>[Votre Nom]</strong>, élève en 2nde GT.</p>
    <p>Passionné(e) par <strong>l'informatique</strong>, je découvre la création 
    de sites web dans le cadre du cours de <strong>SNT</strong>.</p>
    
    <h2>Mes matières préférées</h2>
    <ul>
        <li>Mathématiques</li>
        <li>Sciences et Vie de la Terre</li>
        <li>Histoire-Géographie</li>
        <li>Sciences Numériques et Technologie</li>
    </ul>
    
    <h2>Mes hobbies</h2>
    <p>Pendant mon temps libre, j'aime :</p>
    <ul>
        <li>Écouter de la musique</li>
        <li>Regarder des films</li>
        <li>Jouer aux jeux vidéo</li>
        <li>Faire du sport</li>
        <li>Lire</li>
    </ul>
    
    <h2>Mes projets</h2>
    <h3>Projet actuel</h3>
    <p>Créer un site web personnel avec <strong>HTML</strong>, 
    <strong>CSS</strong> et <strong>JavaScript</strong>.</p>
    
    <h3>Projets futurs</h3>
    <ul>
        <li>Apprendre un langage de programmation</li>
        <li>Créer une application mobile</li>
        <li>Découvrir l'intelligence artificielle</li>
    </ul>
    
    <h2>Contact et liens</h2>
    <p>Vous pouvez visiter mon site préféré : 
    <a href="https://www.wikipedia.org">Wikipédia</a></p>
    
</body>

ATTENTION ! 
- Remplacez [Votre Nom] par votre vrai nom
- Personnalisez les matières et hobbies selon vos goûts
- Vous pouvez changer le site préféré

================================================================================
ÉTAPE 3 : AJOUTER UNE IMAGE (10 minutes)
================================================================================

OPTION A - Si vous avez une photo :

1. Copiez votre photo dans le dossier "Mon_Site_Web"
2. Renommez-la : photo_profil.jpg (ou .png selon le format)
3. Ajoutez ce code APRÈS la ligne <h1>Portfolio de [Votre Nom]</h1> :

<img src="photo_profil.jpg" alt="Photo de profil" width="200">

OPTION B - Si vous n'avez pas de photo :

Ajoutez ce code APRÈS la ligne <h1>Portfolio de [Votre Nom]</h1> :

<p><strong>📸 Photo de profil à venir prochainement !</strong></p>

================================================================================
ÉTAPE 4 : TESTER VOTRE TRAVAIL (10 minutes)
================================================================================

1. Enregistrez votre fichier (Ctrl + S)
2. Ouvrez-le dans le navigateur (double-clic sur index.html)
3. Vérifiez que tout s'affiche correctement :
   ✓ Le titre principal est bien visible
   ✓ Les sous-titres sont plus petits
   ✓ Les listes ont des puces
   ✓ L'image s'affiche (si vous en avez mis une)
   ✓ Le lien fonctionne (cliquez dessus)

================================================================================
ÉTAPE 5 : PERSONNALISATION AVANCÉE (5 minutes)
================================================================================

Ajoutez une nouvelle section avant </body> :

    <h2>Ma citation préférée</h2>
    <p><strong>"[Votre citation préférée]"</strong></p>
    <p><em>- [Auteur de la citation]</em></p>

Nouvelle balise découverte : <em> pour l'italique !

================================================================================
VÉRIFICATION FINALE
================================================================================

Votre page doit contenir :
[  ] Un titre principal <h1>
[  ] Au moins 4 sous-titres <h2>
[  ] Un sous-sous-titre <h3>
[  ] Des paragraphes <p>
[  ] Du texte en gras <strong>
[  ] Au moins 2 listes <ul><li>
[  ] Une image <img> (ou un texte de remplacement)
[  ] Un lien externe <a href>
[  ] Du texte en italique <em>

================================================================================
PROBLÈMES FRÉQUENTS
================================================================================

PROBLÈME : L'image ne s'affiche pas
SOLUTION : 
- Vérifiez que l'image est dans le même dossier que index.html
- Vérifiez l'orthographe du nom de fichier dans src="..."
- Vérifiez l'extension (.jpg, .png)

PROBLÈME : Les listes n'ont pas de puces
SOLUTION : 
- Vérifiez que vous utilisez bien <ul> et </ul>
- Vérifiez que chaque élément est dans <li> et </li>

PROBLÈME : Le lien ne fonctionne pas
SOLUTION :
- Vérifiez que href="..." contient bien http:// ou https://
- Testez le lien directement dans le navigateur
